# 🚀 YouTube Downloader — план развития

Документ на **русском**. Обзор приложения: [../README_ru.md](../README_ru.md).

> Анализ проекта [VidBee](https://github.com/nexmoe/VidBee) и рекомендации по улучшению

---

## 📊 Текущее состояние проекта

| Компонент | Реализация |
|-----------|-----------|
| Фреймворк | Tauri 2 + TypeScript |
| UI | Vanilla CSS (современный дизайн) |
| Бэкенд | Rust (Tauri) + yt-dlp |
| Размер | ~10-15 MB ✅ |

### ✅ Уже реализовано:
- Скачивание видео через yt-dlp
- Выбор качества (best/1080p/720p/480p/audio)
- Выбор кодека (H.264/VP9/AV1)
- Сетевой статус (proxy, VPN, IP)
- Поддержка cookies (Chrome/файл)
- Терминал с логами
- Детекция блокировок контента

## 🎯 План улучшений

### Этап 1: Базовые улучшения (1-2 дня)

- [ ] **Очередь загрузок**
  - Добавить массив задач в state
  - UI для списка загрузок
  - Индикатор статуса каждой загрузки

- [ ] **История загрузок**
  - Сохранение в localStorage или JSON
  - Показ последних загрузок
  - Возможность повторной загрузки

- [ ] **Pause/Resume**
  - Кнопка паузы во время загрузки
  - Перезапуск упавших загрузок
  - Отмена текущей загрузки

---

### Этап 2: UX улучшения (3-5 дней)

- [ ] **Мультиязычность (i18n)**
  - Русский (по умолчанию)
  - English
  - JSON-файлы с переводами
  - Переключатель языка в настройках

- [ ] **Системные уведомления**
  - Уведомление при завершении загрузки
  - Уведомление об ошибках
  - Использовать Tauri notification API

- [ ] **Dark/Light тема**
  - CSS переменные уже готовы
  - Переключатель в header
  - Сохранение выбора пользователя

- [ ] **Горячие клавиши**
  - `Cmd/Ctrl + V` — вставить URL
  - `Cmd/Ctrl + Enter` — начать загрузку
  - `Esc` — отменить загрузку

---

### Этап 3: Продвинутые фичи (1-2 недели)

- [ ] **Плейлисты**
  - Парсинг плейлистов YouTube

### Этап 4: Профессиональные фичи (2+ недели)

## 🏆 Преимущества над VidBee (сохранить!)

| Ваш проект | VidBee |
|------------|--------|
| **Tauri** (~10 MB) | Electron (~150 MB) |
| Быстрый старт | Долгий холодный старт |
| Меньше RAM | Прожорливый Chrome |

## 📅 Приоритеты

1. **Очередь загрузок** — самое важное для UX
2. **History** — полезно для повторных загрузок
3. **Pause/Resume** — профессионально
4. **Browser Script** — удобство
5. **RSS** — продвинутая фича для power users
